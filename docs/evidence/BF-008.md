# BF-008｜统一 API 基础设施

## 目标

为 API 增加统一 requestId、成功响应、异常响应和结构化日志；保留 Swagger 入口。

## 修改文件

- `apps/api/src/infrastructure/request-id.middleware.ts`
- `apps/api/src/infrastructure/response-envelope.interceptor.ts`
- `apps/api/src/infrastructure/api-exception.filter.ts`
- `apps/api/src/infrastructure/pino.logger.ts`
- `apps/api/src/app.module.ts`
- `apps/api/src/main.ts`
- `apps/api/src/infrastructure/*.spec.ts`
- `apps/web/src/App.tsx`
- `apps/web/src/App.test.tsx`

## 业务规则检查

- [x] 每个请求生成或透传安全的 `X-Request-Id`。
- [x] 成功响应统一为 `{ data, meta: { requestId } }`。
- [x] 异常响应统一为 `{ error: { code, message, requestId, details? } }`。
- [x] 错误 code 与 message 解耦，支持前端按 code 判断。
- [x] API 使用 Pino 输出结构化日志。

## 验证命令和结果

```text
pnpm --filter @borderflow/api test       PASS
pnpm --filter @borderflow/api typecheck  PASS
pnpm --filter @borderflow/api build      PASS
pnpm --filter @borderflow/web typecheck  PASS
pnpm --filter @borderflow/web test       PASS
pnpm --filter @borderflow/web build      PASS（存在 Ant Design bundle 大小警告）
```

运行时检查：

- `GET http://localhost:3011/api/health` 携带 `X-Request-Id: demo-req-1` 返回 `200`，响应体包含 `meta.requestId`，响应头回传同一 requestId。
- `GET http://localhost:3011/api/missing` 返回 `404`，响应体为稳定的 `error.code = NOT_FOUND`。
