# BF-013 验收记录：商品与 SKU 基础版

- 商品接口已提供列表、分页、关键词搜索、详情、创建、编辑和状态变更。
- SKU 已提供随商品创建，以及按商品新增/编辑 SKU 的基础接口。
- 商品列表和详情始终使用 JWT 中的商户 ID 查询，客户端不能通过提交 `tenantId` 越权。
- 商品读取需要 `product:read`；创建/编辑需要 `product:write`；状态变更需要 `product:approve`。
- Web 已将“商品与 SKU”骨架替换为真实列表页面，支持搜索、翻页、新建和编辑。
- 真实接口验收：管理员可以登录并查询商品；分析员可以查询但创建商品返回 `MISSING_PERMISSION`。
- API 24 个测试、Web 1 个测试、类型检查和构建均通过。
