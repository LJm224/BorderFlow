# BF-014 验收记录：订单与履约基础版

- 订单接口提供列表、分页、订单号/收货国家关键词搜索、状态筛选和详情。
- 履约状态支持 `待付款 → 已付款 → 拣货中 → 已发货 → 已完成`，并支持取消/退款终态；非法状态跳转返回 `INVALID_ORDER_TRANSITION`。
- 每次状态变化写入 `OrderTimelineEvent`，记录操作者、前后状态和备注。
- 订单读取需要 `order:read`；履约状态变更需要 `order:fulfill`。
- 所有订单查询都带当前 JWT 商户 ID，跨商户订单按不存在处理。
- Web 已将“订单与履约”骨架替换为真实列表、筛选、分页、详情和时间线页面。
- 真实接口验收：管理员可查询；运营推进履约返回 `MISSING_PERMISSION`。
