# BF-016 验收记录：订单履约与库存联动

- 订单从 `PAID` 进入 `PICKING` 时，在同一事务中扣减可用库存、增加锁定库存，并写入 `RESERVATION` 流水。
- 订单从 `PICKING` 进入 `SHIPPED` 时，在同一事务中扣减锁定库存，并写入 `SALE` 流水。
- 订单从 `PICKING` 取消时，在同一事务中恢复可用库存、释放锁定库存，并写入 `RELEASE` 流水。
- 库存不足或找不到对应库存时，订单状态不会变化，接口返回明确错误码。
- 库存查询按订单所属店铺和当前商户校验，避免跨商户库存操作。
- API 测试覆盖锁定、释放、库存不足和非法状态流转。
