# BF-015 验收记录：库存管理基础版

- 库存接口提供分页、按 SKU/商品/仓库关键词搜索和详情。
- 库存调整支持入库、出库和盘点调整，并记录 `InventoryTransaction`。
- 出库不能超过可用库存，非法数量返回 `INVALID_INVENTORY_QUANTITY`，库存不足返回 `INSUFFICIENT_STOCK`。
- 库存读取需要 `inventory:read`；调整需要 `inventory:write`。
- 库存查询和调整会校验仓库所属店铺的商户 ID，跨商户库存不可访问。
- Web 已将“库存”骨架替换为真实列表、搜索、分页、预警展示和调整弹窗。
- 真实接口验收：仓库账号可查询库存；运营账号调整库存返回 `MISSING_PERMISSION`。
