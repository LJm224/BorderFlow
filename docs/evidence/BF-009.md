# BF-009｜登录、刷新会话和当前用户

## 目标

实现基于商户编码的登录、15 分钟 Access JWT、30 天 Refresh Token 轮换、当前用户查询和当前会话退出。

## 接口

- `POST /api/auth/login`
- `POST /api/auth/refresh`
- `POST /api/auth/logout`
- `GET /api/auth/me`

## 安全规则

- 登录使用 `tenantCode + email + password`。
- 密码使用 bcrypt 校验，登录失败统一返回 `INVALID_CREDENTIALS`。
- JWT payload 只包含 `sub`、`tenantId`、`role`。
- Refresh Token 只以 SHA-256 hash 存入 `RefreshSession`。
- Refresh Token 使用 HttpOnly、SameSite=Lax Cookie，并在刷新时轮换。
- 退出会撤销当前 RefreshSession 并清理 Cookie。
- `/me` 通过 Bearer Access Token 校验用户和租户归属，不返回密码字段。

手工 API 验证：

- 正确账号登录返回 `200`、Access Token 和 `Set-Cookie`。
- 错误密码返回 `401`，错误 code 为 `INVALID_CREDENTIALS`。
- 携带 Access Token 请求 `/api/auth/me` 返回用户和 tenant 信息。
- 携带 Refresh Cookie 请求 `/api/auth/refresh` 返回新 Access Token 和新 Cookie。
- `/api/auth/logout` 返回 `200` 并清除 Cookie。

## 已知限制

- 当前没有账号锁定、验证码和“退出所有设备”功能。
- 角色权限 Guard 属于 BF-011；当前 JWT Guard 只负责认证和用户归属校验。
