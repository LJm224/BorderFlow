# BF-010｜租户隔离 Guard

## 目标

将当前租户固定绑定到 JWT 用户上下文，统一提供租户上下文、参数装饰器、查询/写入 helper 和跨租户拒绝 Guard。

## 修改文件

- `apps/api/src/tenants/tenant-context.ts`
- `apps/api/src/tenants/current-tenant.decorator.ts`
- `apps/api/src/tenants/tenant-query.helper.ts`
- `apps/api/src/tenants/tenant-isolation.guard.ts`
- `apps/api/src/tenants/tenant.module.ts`
- `apps/api/src/auth/auth.controller.ts`
- `apps/api/src/tenants/*.spec.ts`

## 规则

- 当前 `tenantId` 只从已验证 JWT 的 `request.user.tenantId` 获取。
- 查询必须使用 `tenantWhere(currentTenantId, where)` 注入服务端租户条件。
- 写入必须使用 `tenantData(currentTenantId, data)`，忽略客户端携带的 `tenantId`。
- URL 参数、query 或 body 中出现其他租户的 `tenantId` 时，Guard 返回 `TENANT_ACCESS_DENIED`。
- `/api/auth/me` 已同时启用 JWT 认证和租户隔离 Guard。
